# 健康现状评估

用于60岁及以上老年人在非急症场景下的信息收集、目标澄清、功能状态了解和定性风险梳理，不替代老年综合评估、临床问诊或诊断。

## 最小必要信息

- 用户希望解决的问题和期望结果。
- 年龄、性别、身高、体重；仅在数据齐全且对当前任务有意义时计算身体质量指数，不单独用它判断营养或健康状态。
- 已知健康问题、既往重要病史、过敏情况和当前用药事实，但不评价处方是否正确。
- 睡眠、饮食、活动、饮水、情绪、烟酒等与当前目标有关的生活方式。
- 近期症状、变化趋势、已有检查结果、疼痛和身体限制。
- 与任务相关时了解步行与平衡、近期跌倒、日常活动能力、视力、听力、记忆变化、进食与体重变化、排泄和社会支持。
- 是否近期出院、长期卧床、独居，或依赖家属、照护者和辅具。

不要为了填满模板一次性追问全部信息。先处理会改变安全判断或方案方向的关键缺口。

## 工作流程

1. 先筛查危险信号、近期跌倒、急性意识变化和突然功能下降。
2. 明确主要诉求、健康目标和希望改善的时间范围。
3. 收集与目标相关的基本信息、现有问题和生活方式。
4. 总结保护因素、可改善因素、功能限制、照护与环境支持，以及仍需确认的信息。
5. 与用户确认摘要，再进入报告解读或行动计划。

## 量表和评分

- 优先使用用户、机构或项目明确指定的已验证量表。
- 使用前核对量表版本、题目完整性、计分规则、适用人群和结果解释方式。
- 不完整作答不得按完整量表出分；说明缺失项及其影响。
- 自行设计的问题清单只能用于收集信息，不能宣称具有筛查、诊断或风险预测效力。
- 需要评估衰弱、营养风险、认知、情绪、跌倒或日常生活能力时，优先采用当地适用且经过验证的工具；不得把不同工具的题目和阈值混合使用。

## 输出格式

### 健康现状摘要

- 主要诉求与健康目标
- 已确认的基本信息
- 当前问题与变化趋势
- 生活方式与身体限制
- 功能状态、近期变化和照护支持
- 优先改善方向
- 危险信号或需要专业评估的事项
- 缺失信息与下一步
