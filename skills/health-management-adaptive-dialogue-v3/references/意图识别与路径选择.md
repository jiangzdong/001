# 意图识别与路径选择

用于首次输入、用户改变话题或上一轮无法判断目标时。先识别行动目的，不要求用户说出专业领域名称。

## 主路径

| 用户意图 | 常见表达 | 下一步 |
|---|---|---|
| 危险或急性变化 | 突然剧烈头痛、胸痛喘不上气、突然说不清话 | 立即安全分流 |
| 具体症状 | 头痛、头晕、腿疼、乏力、睡不好 | 症状专项追问 |
| 血糖管理 | 血糖高、低血糖、餐后血糖波动 | 血糖领域问答 |
| 按摩放松 | 哪里能按、是否适合按摩、怎么放松 | 按摩安全核对 |
| 康复管理 | 术后恢复、出院计划、辅具、生活能力 | 康复领域问答 |
| 睡眠健康 | 入睡困难、夜醒、早醒、日间困倦 | 睡眠领域问答 |
| 脑健康 | 记性变化、认知活动、日常安全 | 脑健康领域问答 |
| 运动康复 | 散步、力量、平衡、动作训练 | 运动领域问答 |
| 综合健康评测 | 想了解身体状况、做个健康评估 | 通用评测 |
| 报告或数据 | 帮我看体检报告、这个数值是什么意思 | 数据核对后解读 |
| 药物处方 | 吃什么药、能不能停药、剂量怎么改 | 说明不能调整，建议咨询医生或药师 |
| 心理问题 | 持续绝望、自伤想法、严重精神症状 | 心理或紧急支持路径 |
| 非健康问题 | 天气、娱乐、设备操作等 | 简短说明服务范围，不启动问卷 |

## 判断规则

1. 危险信号永远覆盖其他路径。
2. 用户点名具体症状时，不先要求完成综合问卷。
3. 用户点名明确领域时直接进入该领域，不再问“您想了解什么”。
4. 多个问题并存时，以用户最想先解决的问题作为主路径；只补充会影响安全或方案的协同领域。
5. “怎么办”“怎么解决”通常表示需要行动方案，但不能据此推断诊断。

## 唯一一次意图澄清

只在两种路径都合理且会导致不同追问时使用：

> 您这次最想先了解哪一项？

- 现在的不舒服
- 日常健康评测
- 看报告或数据
- 其他情况

用户可以说出选项文字、序号或自己的表达。仍无法判断时，询问是否愿意开始通用健康评测；用户拒绝则结束。

## 话题切换

- 新问题明显不同：确认“我们先看新问题”，保存但暂停原路径。
- 新问题是原症状的补充：合并信息，不重新路由。
- 新问题包含危险信号：立即覆盖原路径进入安全处置。
