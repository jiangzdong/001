## 1. 结论摘要

本期只交付一个可运行角色：**站点咨询顾问**。产品运行在公共竖屏数字人终端上，面向到站长者提供站点介绍、服务导航、健康知识、活动查询，以及在完成本人身份认证后查询本人会员、积分和余额信息。

蓝湖稿的视觉与流程框架可以保留，但不能直接进入开发。以下问题已经在本修正版中纠正：

1. 不再向用户展示模型思考过程、内部 skill 名称、工具调用或权限判断过程。
2. 人脸认证与权限判断改由可信策略层和业务后台决定，模型只能识别意图、提取业务参数和生成允许范围内的自然语言回复。
3. 不再在公共屏幕上列出多个疑似用户的头像与姓名，避免泄露他人身份。
4. 增加摄像头告知、认证超时、会话清理、敏感数据遮罩、失败关闭和审计日志边界。
5. 明确推荐问题有两个来源：机构配置的首页默认问题，以及模型基于最近一次回答生成的会话内追问；两者不能互相覆盖。
6. 将无语音、无法理解、网络异常、业务接口异常、无权限和认证失败拆分成不同状态与恢复路径。
7. 将长篇模型输出改为“先给结论、再提供展开”，避免公共终端长时间占用和长者听读负担。
8. 明确本轮只在当前 Windows Electron 项目中本机演示；人脸、会员、积分、余额和权限均使用可复现的本地演示状态，不依赖 Android 或生产后台。
9. 语音交互采用“默认自动聆听 + 可编辑输入框”一体化方案：语音转写和键盘输入落入同一输入栏；普通问题识别后短暂倒计时自动发送，敏感问题和低置信结果必须由用户确认；键盘聚焦、修改、清空、切屏或退出会立即取消自动发送并作废迟到识别结果。
10. 回答文字、本地 TTS 和数字人口型恢复为同一轮次：PCM 音频作为主时钟，Viseme 时间线与音量分析共同驱动本地口型；用户重新开麦、静音、返回首页、进入身份流程或退出时必须取消旧播报并清理旧口型状态。

## 3. 原需求主要问题与修正

| 严重度 | 原需求问题 | 影响 | 修正结论 |
|---|---|---|---|
| 阻断 | 默认展示“思考过程”，稿中还出现内部 skill 加载文案 | 泄露内部实现，可能暴露敏感上下文，也违反当前项目约束 | 用户界面只展示可公开的最终答复、必要进度和可解释的业务依据；永不展示隐式推理或工具调用 |
| 阻断 | 由模型判断是否需要人脸认证、是否有权限 | 可被提示注入、误判或绕过，形成越权查询 | 由确定性的 `Policy Engine` 根据意图、数据级别、当前身份和机构权限返回决策；模型无权放行 |
| 高 | 多人或相似人脸时展示多人头像与昵称供选择 | 公共终端泄露其他会员身份，且存在误选风险 | 不展示候选人列表；提示仅保留一人面对摄像头后重试，或使用本人会员号加本地 PIN 的触控兜底 |
| 高 | 缺少人脸采集告知、用途、保存周期和退出方式 | 隐私与合规风险 | 认证前显示简短告知；只上传或处理认证所需数据；默认不落盘原始照片；支持取消并返回非个性化问答 |
| 高 | “查询本人”“查询他人”“查询运营数据”的权限规则不完整 | 容易把个人信息或站点经营数据错误返回给普通用户 | 明确数据分级和角色矩阵；任何未明确授权的查询默认拒绝 |
| 高 | 退出使用“机构登录密码” | 容易在公共场所暴露主账号密码，也不利于限流和更换 | 使用单独的 6 位终端退出 PIN；失败限流；不复用机构主账号密码 |
| 高 | 会话何时创建、何时结束、超时后如何清理不完整 | 会串会话、遗留个人信息或错误延续上下文 | 有效首问创建会话；X、退出模式、超时或应用重启立即结束并清理敏感状态 |
| 高 | 动态积分解释由模型生成，示例中“健康讲座/签到活动”前后不一致 | 演示时同一用户可能得到不同结果 | 数值、来源明细和兑换规则全部来自同一份本地演示数据；模型只改写已提供事实，不做推算 |
| 高 | 医疗文案包含“预防老年痴呆”等承诺式表达 | 医疗误导与污名化风险 | 改为“认知训练与日常健康管理”，不承诺预防、诊断或治疗疾病 |
| 中 | 首页默认推荐问题与回答后动态追问没有明确优先级 | 前端容易混用、缓存错误或展示过期问题 | 首页只读机构配置；会话内只显示最近一轮回答生成的追问；进入下一轮立即隐藏旧追问 |
| 中 | “允许一定延迟”不可测试 | 无法制定性能门槛 | 增加可量化的反馈、识别、首字、首音频和降级标准 |
| 中 | 无语音、无语义、网络失败、接口失败都接近同一错误页 | 用户不知道该重说、重试还是放弃 | 为每类错误提供不同文案、按钮和自动恢复规则 |
| 中 | “你/您”、角色数、专家数、区域数和示例文案不一致 | 降低可信度，给研发和测试造成不同理解 | 对长者统一使用“您”；本期角色固定为 1 个，其余角色不进入可点击功能范围 |
| 中 | 语音是主入口，但触控兜底不完整 | 嘈杂环境、听力或言语障碍用户无法完成任务 | 核心路径必须具备等价触控入口，包括推荐问题、停止、重试、认证取消、退出和历史查看 |

## 4. 产品目标与边界

### 4.1 一句话目标

让到站长者在无需学习复杂操作的情况下，通过语音为主、触控为辅的数字人终端，快速了解站点服务，并安全查询仅属于本人的会员信息。

### 4.2 目标用户

- **到站长者**：首次来访者、普通访客、已注册会员。
- **站点工作人员**：负责机构登录、进入数字人模式和终端维护。
- **机构管理员**：配置首页的 3 条默认推荐问题、终端退出 PIN 和角色可用状态。

### 4.3 已确认的演示平台

本修正版按用户确认的“本机显示演示”执行：

- Windows x64 Electron 应用。
- 9:16 竖屏触控终端，目标分辨率 1200 × 1920，缩放 100%。
- 默认麦克风和扬声器可用；摄像头存在时展示实时预览，不存在时仍可通过演示状态完成流程。
- 语音为主输入，触控提供完整兜底。
- 优先复用项目已有本地 ASR、TTS、数字人口型和 Electron 运行链路。
- 演示数据、权限、推荐问题和身份结果存放在本机，不依赖会员后台或真实人脸库。

蓝湖中的 Android 设备说明在本轮全部忽略，不作为设计、开发或验收条件。

### 4.4 本期范围（P0）

- 机构账号登录后的“工作台模式 / 数字人模式”选择。
- 数字人模式只开放“站点咨询顾问”。
- 首页欢迎、3 条机构配置的默认推荐问题和语音入口。
- 站点介绍、服务导航、活动信息、一般健康知识问答。
- 本人会员、积分、余额查询；查询前按策略触发身份认证。
- 明确拒绝查询他人个人信息和无权查看的站点经营数据。
- 多轮会话、历史上滑查看、流式文字、语音播报、停止和重播。
- 人脸认证成功、失败、超时、取消、多脸、非库内用户等状态。
- 本机演示场景切换器，可稳定复现认证成功、失败、超时、多脸、无语义和接口错误等状态；该入口仅用于演示控制，不进入长者主界面。
- 无语音、无法理解、服务超时、接口失败、离线和恢复路径。
- 机构端配置 3 条首页推荐问题，每条不超过 12 个汉字。
- 公共终端的会话超时、敏感信息遮罩和状态清理。

### 4.5 暂不包含

- 其余 8 个专家角色的真实能力与可点击入口。
- 疾病诊断、治疗方案、用药调整、疾病预防承诺。
- 代他人查询、修改积分、余额充值、支付、积分兑换和会员资料编辑。
- 站点经营报表、工作人员运营后台和跨机构数据查询。
- 模型思考过程、内部工具、内部 skill、系统提示词或安全策略的展示。
- 真实人脸比对、活体检测、真实会员后台、真实积分/余额、生产权限系统和生产数据持久化。
- Android APK、Android 摄像头 SDK 或 Android 设备适配。

## 6. 统一状态机

| 状态 | 用户看到的内容 | 可执行操作 | 退出条件 |
|---|---|---|---|
| `IDLE` 待激活 | 欢迎语、3 条默认问题、点按说话 | 点推荐问题、开始说话、退出模式 | 用户发起提问 |
| `LISTENING` 聆听中 | “我在听”、实时转写、我说完了 | 结束、取消 | 有效语音、取消、超时 |
| `TRANSCRIBING` 识别中 | “正在识别” | 取消 | 识别成功或失败 |
| `EDITING` 键盘编辑 | 可编辑识别文字或直接输入 | 修改、清空、发送、重新开麦 | 手动发送、重新开麦、返回 |
| `AUTO_SUBMIT_PENDING` 自动发送待定 | 已识别文字、约 1.5 秒倒计时、可暂停提示 | 聚焦修改、清空、立即发送 | 到时发送或任一取消动作 |
| `CONFIRM_TRANSCRIPT` 识别确认 | 敏感或低置信文字、明确确认按钮 | 修改、确认发送、清空、重新说 | 确认、修改或取消 |
| `THINKING` 处理中 | “让我想想”及非敏感进度 | 取消本轮 | 首段公开答复、认证请求或错误 |
| `AUTH_REQUIRED` 需要认证 | 说明为什么需要认证 | 开始认证、取消 | 用户选择 |
| `AUTHENTICATING` 认证中 | 摄像头画面、单人取景提示、倒计时 | 取消、重试 | 成功、失败、超时 |
| `RESPONDING` 回答中 | 流式公开答复、数字人回答动效 | 停止播报、继续提问、退出会话 | 播放完、被停止或新一轮打断 |
| `ERROR_RECOVERABLE` 可恢复错误 | 对应错误原因和下一步 | 重说、重试、返回首页 | 用户操作或自动恢复 |
| `ENDING` 会话结束 | 简短结束提示 | 返回首页 | 敏感状态清理完成 |

任何状态下点击 X 都必须先停止录音、TTS、数字人帧流和在途请求，再结束当前会话并回到 `IDLE`。

## 7. 功能需求

### FR-001 进入数字人模式

- 站点工作人员登录机构账号后看到“工作台模式 / 数字人模式”。
- 选择数字人模式后进入角色列表；本期只有“站点咨询顾问”可点击。
- 未开放角色显示“敬请期待”，不得获得焦点后触发空页面。

### FR-002 首页与默认推荐问题

- 首页展示站点名称、当前时间、角色名、能力简述、语音入口和 3 条默认推荐问题。
- 默认问题来自机构配置；读取失败时使用产品内置默认值并记录非敏感错误码。
- 统一对长者使用“您”，不显示内部版本、调试或模型状态。

### FR-003 语音输入

- 首页进入可交互状态且麦克风、本机识别服务可用时，默认自动进入 `LISTENING`，无需先点击麦克风；界面在 300ms 内给出可见反馈。
- 麦克风按钮是自动聆听的暂停/恢复控制：聆听中点击后立即停止并释放录音，暂停时再次点击恢复自动聆听，不把“停止”误当作提交未完成语音。
- 支持实时转写；转写仅用于本轮交互，除非另有明确授权，不落盘保存原始音频和完整文本。
- 点击“我说完了”或检测到可配置静音时长后结束拾音。
- 未检测到有效语音时不创建会话；先显示“没有听到，请再说一次”，然后在自动语音未暂停、输入框未编辑且页面仍可聆听时自动重试。麦克风权限拒绝、模型缺失或服务不可用属于不可自动重试错误，必须停止循环并保留键盘/触控入口。
- 一般问答播报完成后自动恢复聆听；键盘聚焦、自动语音暂停、进入身份流程、打开退出弹窗或页面离开咨询态时不得自动抢占麦克风。
- 识别通道按 `Electron 离线 SenseVoice → Vite 本机离线接口 → 显式启用的浏览器 Web Speech 降级` 排序。浏览器 Web Speech 默认关闭，避免在公共健康终端上隐式使用浏览器厂商云识别。
- 原生录音和本机网页录音复用自适应 VAD、前滚录音、静音结束和最长 45 秒保护；取消后必须释放音频轨道。
- 每轮识别使用单调递增的 operation ID。编辑、清空、重新开麦、切屏、返回首页和退出会使旧 operation 失效；迟到的 preview 或 final 不得覆盖当前输入、跳转页面或重新启动倒计时。

### FR-003A 识别文字与自动发送

- 实时转写和最终识别文字都写入同一个可编辑输入框；输入框同时接受实体键盘、屏幕键盘和扫码式键盘事件。
- 普通站点问题在最终识别后进入 1.5 秒自动发送待定态。倒计时必须显示“可点击修改”，用户也可点击发送立即提交。
- 自动发送票据必须同时校验 countdown ID、识别 operation ID、文本修订号、完整文本、当前页面和退出弹层状态；任一不一致都不得发送。
- 输入框聚焦、修改、清空、重新开麦、页面切换、进入身份流程、返回首页和打开退出弹窗必须同步取消倒计时，不能只等待 React 下一次渲染清理。
- 涉及会员、积分、余额、账户或本人信息的识别结果一律进入手动确认，不自动发送。
- 非敏感问题识别置信度低于 0.72 时进入手动确认；本地 ASR 不返回置信度时按普通问题自动、敏感词优先确认处理。
- 自动发送和手动发送统一进入同一个意图路由和单次提交锁；同一事件循环内的倒计时、回车、点击或双击竞态最多提交一次。
- 倒计时视觉可每 100ms 更新，但读屏提示保持稳定文案，避免连续播报小数倒计时。

### FR-004 触控等价路径

- 用户可以通过默认问题发起首轮会话，通过动态推荐问题发起下一轮。
- 停止播报、重播、重试认证、取消认证、返回首页和退出会话必须可触控完成。
- 不允许只靠颜色、声音或倒计时传达关键状态。
- 首页和会话页保留同一输入框，键盘输入与语音识别共用发送、敏感策略、意图路由和错误恢复，不建设两套不一致的问答逻辑。
- 输入框获得焦点时键盘优先：立即停止并作废录音/识别，保留当前文字；编辑期间不得自动恢复聆听。输入框失焦且内容为空、回答已结束、自动语音未暂停时可恢复自动聆听。
- 输入框支持 Enter/发送键提交、可见清空按钮、明确焦点样式和读屏标签；发送按钮在空文本或识别中禁用。

### FR-005 会话生命周期

- 点击默认问题，或首条有效语音识别完成时，创建一个会话 ID。
- 后续问题沿用同一会话 ID，直到 X、退出数字人模式、应用重启或超时结束。
- 90 秒无输入时提示“还需要继续吗”；再等待 20 秒无操作则自动结束并清理会话。两个时长应支持机构配置。
- 新用户开始前不得保留上一用户的姓名、认证态、积分、余额、历史对话或推荐问题。

### FR-006 意图与演示权限策略

- 模型输出仅包含受约束的业务意图和参数，不包含最终授权结论。
- 本地 `Demo Policy Engine` 根据意图、数据分级、演示身份状态和演示角色返回 `ALLOW`、`AUTH_REQUIRED` 或 `DENY`。
- `AUTH_REQUIRED` 时前端展示认证原因；`DENY` 时给出不泄露权限细节的明确拒绝。
- 模型和界面不得绕过本地策略模块直接读取演示会员数据。

### FR-007 本人信息查询

- 可查询本人会员状态、积分、余额和后台明确开放的本人信息。
- 数字值、明细、有效期和兑换规则必须来自统一的本地 fixture；回答中不得补写、猜测或重新计算 fixture 中不存在的数据。
- 账户结果区域显示低干扰的“演示数据”标记，避免把本机样例误认为真实会员信息。
- 页面默认显示脱敏姓名，例如“王*庆”；离开结果页或会话结束后立即清理。

### FR-008 人脸认证演示

- 只有本地策略层返回 `AUTH_REQUIRED` 时才能启动认证演示。
- 启动前说明用途：“用于确认是您本人并查询本次信息”，并提供“开始识别 / 暂不识别”。
- 默认成功场景在 3 秒后返回演示身份；通过隐藏的演示控制器可切换失败、超时、多脸和非库内状态。
- 单次流程最长 15 秒，最多自动或手动重试 2 次；超出后返回非个性化问答。
- 识别成功后显示脱敏姓名和 3、2、1 倒计时，再回到原问题继续查询，不要求用户重复提问。
- 失败、非库内用户、多脸或超时分别使用稳定错误码，但用户侧只显示安全、可执行的提示。
- 多脸或多候选时不展示其他人的头像和姓名，提示保持画面内只有本人后重试。
- 本轮不宣称完成真实人脸比对、活体检测或生产身份认证；摄像头画面只用于演示取景反馈。

### FR-009 认证触控兜底演示

- 摄像头不可用、用户不愿使用人脸或连续失败时，可点击“使用演示身份”继续；该按钮只在 `DEMO_MODE` 下存在。
- 用户也可取消并继续非个性化问答。

### FR-010 回答展示与语音播报

- 用户只看到可公开的最终答复，不显示思考过程、工具调用、skill、系统提示词或原始权限规则。
- 回答优先给出结论和下一步；默认首屏正文建议不超过 180 个汉字，超出内容分段并提供“继续听/展开详情”。
- 模型处理阶段不播报；第一段完整、可公开的句子可用后开始 TTS，并与后续文字流式衔接。
- 点击喇叭可停止当前播报；再次点击从当前回答开头重播。新一轮提问会打断旧播报和旧数字人帧流。
- GPU 数字人不可用或帧落后时自动降级到本地 TTS 与本地口型，不阻断回答。
- V1.5.2 站点固定回答至少播报“结论标题 + 正文”；Electron 优先使用 `kioskBridge.synthesizeSpeechStream/synthesizeSpeech`，Vite 本机演示使用同源离线 TTS 接口，浏览器厂商语音仅可作为明确标识的降级。
- 本地 TTS 返回的 PCM、采样率、Viseme 与对齐信息进入同一个 Web Audio 播放时钟；`AnalyserNode` 只做受控能量强调，Viseme 时间线决定主要嘴型，不能用无声定时动画冒充口型同步。
- 播报开始时暂停自动聆听；播报结束后在页面、焦点、隐私和暂停条件允许时恢复聆听。用户点击麦克风发起新问题时必须立即打断旧 TTS、清空旧 analyser/timeline，并作废旧 `turn_id`。

### FR-011 推荐问题

- 首页：只展示机构配置的 3 条默认问题。
- 会话内：模型只能基于最近一次公开答复生成 3 条追问，每条不超过 12 个汉字，不得包含个人敏感信息。
- 用户进入下一轮后立即隐藏上一轮追问；历史回答不重复显示旧追问。
- 动态追问生成失败时回退到当前意图对应的安全模板，不影响正文回答。

### FR-012 多轮对话与历史

- 当前会话支持上滑查看历史对话，进入新一轮时自动滚动到本轮输入和状态。
- 只有当前轮显示进度、操作按钮和推荐问题。
- 历史中个人数据保持脱敏；会话结束后不在公共页面恢复。

### FR-013 异常与恢复

| 异常 | 用户提示 | 可恢复操作 |
|---|---|---|
| 没有检测到语音 | “没有听到您说话，请再说一次” | 自动语音开启时短暂提示后重试；也可暂停语音、键盘输入或点推荐问题 |
| 识别结果无有效语义 | “我还没听明白，请换一种说法” | 重说、点推荐问题 |
| 麦克风不可用/权限拒绝 | “麦克风暂时不可用” | 使用触控问题、重试 |
| 模型超时或网络异常 | “服务暂时没有响应” | 重试本轮、返回首页 |
| 演示数据读取失败 | “暂时无法查询账户信息” | 重置演示数据、稍后重试；禁止模型猜测 |
| 人脸认证失败 | “没有确认到您的身份” | 重试、取消、可用时切换会员号 + PIN |
| 无权限 | “无法为您查询他人的个人信息” | 返回一般问答 |
| TTS/数字人失败 | 文字继续显示 | 重试播报；数字人降级但不阻断正文 |

### FR-014 退出数字人模式

- 点击“退出数字人模式”显示专用 6 位终端退出 PIN 弹窗。
- X 或取消关闭弹窗并保留当前模式。
- PIN 正确：停止所有媒体与请求、清理公共会话，保留机构登录态，返回模式选择页，再按工作台要求恢复屏幕方向。
- PIN 错误：提示“退出码不正确”，弹窗保留；连续 5 次失败后锁定 5 分钟并记录安全事件。

### FR-015 机构端推荐问题配置

- 只有机构管理员或被授权的工作人员可编辑。
- 固定 3 条，每条 1 至 12 个汉字；去除首尾空格，不允许三条完全重复。
- 保存前做敏感词、医疗承诺和个人信息检查；保存成功后下一次进入首页生效。
- 保存失败保留用户输入并显示明确原因，不以 toast 一闪而过作为唯一反馈。

### FR-016 健康安全边界

- 只提供健康管理与站点服务信息，不进行疾病诊断、治疗、用药调整或效果承诺。
- 出现紧急症状时给出清晰的紧急就医建议；不使用“预防老年痴呆”等承诺或污名化表述。
- 回答需遵守当前项目的 `routine / attention` 两级健康管理结果边界。

## 8. 本机演示数据与模块边界

本机演示把大模型放在受约束的编排层，不能直接修改演示会员数据：

```text
用户输入
  -> ASR / 触控问题
  -> 意图识别与参数提取
  -> Demo Policy Engine（确定性权限判断）
     -> ALLOW：读取本地演示 fixture
     -> AUTH_REQUIRED：进入本地身份演示后重新判定
     -> DENY：返回安全拒绝
  -> 响应编排（只使用 fixture 中的事实）
  -> 文字流 + TTS + 数字人口型
```

建议的本地模块契约：

- `createDemoSession()`：创建本地会话，返回 `sessionId` 和过期时间。
- `classifyIntent()`：返回 `intent`、`slots`、`confidence`；不得返回最终授权。
- `evaluateDemoPolicy()`：返回 `ALLOW | AUTH_REQUIRED | DENY`。
- `runIdentityDemo(scenario)`：返回 `success | failed | timeout | multiple | not_found` 和匿名化演示主体 ID。
- `getDemoMemberSummary(subjectId)`：返回积分、余额、会员状态和固定明细。
- `loadDemoAdvisorPrompts()` / `saveDemoAdvisorPrompts()`：本地读取或保存 3 条首页问题。
- `endDemoSession()`：结束会话并清理本轮身份及敏感显示状态。

### 8.1 固定演示数据

本轮使用一份单一事实源，禁止在组件中散落硬编码：

| 字段 | 演示值 |
|---|---|
| 用户 | 王*庆 |
| 会员状态 | 有效 |
| 当前积分 | 45 分 |
| 当前余额 | 只从 fixture 读取；由实现时统一设定 |
| 积分来源 | 健康讲座 3 次 × 5 分；养生理疗 2 次 × 10 分；带朋友参观奖励 10 分 |
| 兑换规则 | 若 fixture 未配置则不回答，不沿用蓝湖示例自行推断 |
| 首页默认问题 | 我第一次来，简单介绍下；帮我查一下我有多少积分；晚上睡不好，有什么好办法 |

演示控制器的场景和数据在应用重启后恢复默认；机构推荐问题可选择保存在本机 `localStorage` 或 Electron 用户数据目录。

## 9. 隐私、安全与日志

- 默认不保存原始人脸图片、视频帧和原始语音；确需保存时必须单独提供法律依据、用途、期限和删除机制。
- 演示身份只绑定当前本地会话，随会话结束立即失效。
- 公共屏幕不得展示完整姓名、手机号、会员号、身份证号、住址或其他可识别信息。
- 不记录完整用户提问、健康内容、积分、余额或模型正文到运行指标；只记录阶段、耗时、成功状态和非敏感错误码。
- 本地策略默认拒绝跨用户、缺失演示身份或未声明的数据查询。
- 对模型输入执行提示注入防护；外部内容不能修改权限策略、系统提示或工具白名单。
- 摄像头和麦克风状态必须有可见提示，并支持用户取消。

## 10. 可用性与无障碍要求

- 主操作触控热区不小于 56 × 56 CSS px；次要控件不小于 48 × 48 CSS px。
- 正文等效字号建议不小于 24px，关键按钮和状态文字更大；正文对比度至少 4.5:1。
- 关键状态同时使用文字、形状或图标，不只依赖颜色、声音或动画。
- 提供明确焦点样式与顺序；核心路径支持键盘/外接控制设备操作，便于维护和无障碍测试。
- 动画不应遮挡文字或成为完成任务的前提；倒计时必须可读并提供取消。
- 长回答先摘要，避免连续播报超过 45 秒；用户可停止、重播或继续听。

## 11. 性能与可靠性门槛

- 用户触发后 300ms 内出现视觉反馈。
- 15 秒以内语音结束后，目标设备本地 ASR 最终结果 P95 不超过 2 秒；无法达到时显示持续进度。
- 云端回答首个可公开文字目标 P95 不超过 5 秒；超过 8 秒显示可取消的超时提示。
- 首个完整句可用后，TTS 首音频目标不超过 2 秒。
- 数字人帧流不能阻塞文字与语音；落后或不可用时在 1 秒内切到本地口型降级。
- 会话结束后 1 秒内停止录音、播报和在途请求，并清理敏感界面状态。
- 不得把静态页面、浏览器预览、APK/EXE 构建或单次截图当作真实终端运行验收。

| AC-014 | 90 秒无操作 | 不进行操作 | 先询问是否继续；再过 20 秒自动结束并清理个人状态 |
| AC-015 | 退出弹窗 | 输入错误 PIN | 不退出；显示错误；5 次失败锁定 5 分钟 |

| AC-017 | 机构配置页 | 保存 3 条合规问题 | 保存成功；重新进入首页后显示新配置 |
| AC-018 | 机构配置页 | 输入超过 12 字、重复或违规问题 | 阻止保存并逐项指出原因，保留已输入内容 |
| AC-019 | 云端/GPU 服务异常 | 发起一般问答 | 文字或本地能力按策略降级；数字人帧流失败不阻断核心路径 |
| AC-020 | 会话结束 | 新用户开始使用 | 不可看到上一用户姓名、认证态、账户数据、历史或推荐问题 |

| AC-022 | 自动发送倒计时中 | 在 1.5 秒结束前聚焦、修改或清空 | 立即取消自动发送；修改结果保留；超过倒计时时间也不提交旧文字 |
| AC-023 | 自动发送临界点 | 约 1.5 秒时点击发送、双击或按两次 Enter | 同一问题最多提交一次，不重复跳转或创建会话 |
| AC-024 | 旧语音仍在识别 | 编辑文字、重新开麦、切屏、返回首页或打开退出弹窗 | 旧 preview/final 到达后被忽略，不覆盖、不提交、不跳转 |
| AC-025 | 高置信识别“帮我查一下会员积分” | 等待 5 秒 | 不自动发送；显示“涉及会员信息，请确认文字后发送”；确认后才进入身份告知 |
| AC-026 | 低置信识别普通服务问题 | 等待 5 秒 | 不自动发送；显示低置信确认；修改或确认后只提交一次 |
| AC-027 | 输入框正在编辑 | 会话自动聆听条件满足 | 不抢占焦点、不启动麦克风；用户点击麦克风后才切回语音 |
| AC-028 | Web Speech 未显式启用且离线识别不可用 | 点击麦克风 | 提示本地识别未就绪，键盘仍可完整完成核心问答 |
| AC-029 | 首页加载完成，麦克风与本机 ASR 可用 | 不点击任何按钮 | 自动进入聆听并显示可见状态；不会先创建空会话 |
| AC-030 | 自动聆听中且环境无有效语音 | 等待一次 VAD 超时 | 显示无语音提示后自动重试，不停留在永久错误态；暂停语音后不再重试 |
| AC-031 | 自动聆听或实时转写中 | 点击输入栏并键盘编辑 | 立即释放麦克风、保留当前文字、取消倒计时；编辑期间不重新开麦 |

## 14. 本机演示实现约定

以下内容不再阻断开发，按本地配置实现：

1. 目标固定为当前 Windows Electron 竖屏应用。
2. 身份流程固定为演示状态机，可选显示摄像头预览，不做真实人脸匹配。
3. 积分、余额、会员状态、权限和明细固定来自本地 fixture。
4. 退出 PIN 存放在本地配置中，不写死在 UI 文案或仓库公开说明里。
5. 隐藏演示控制器至少支持：默认成功、认证失败、多脸、超时、无语义、数据读取失败、模型超时。
6. 账户结果显示“演示数据”；运行日志只记录场景、耗时、成功状态和错误码。
7. 未开放角色保持“敬请期待”且不可点击。
8. 演示启动或重置后恢复默认身份、默认推荐问题和无历史会话状态。
9. V1.5.2 首页和会话页共用输入法式混合输入组件；默认自动聆听、语音转写和键盘编辑使用同一输入栏、敏感策略、意图路由和单次提交锁。
10. Electron 使用项目内置离线 ASR/TTS；浏览器开发模式仅请求同源本机语音接口。识别文字、输入文字、PCM、Viseme 和会员问题不写入存储、控制台或遥测。
11. 活跃站点页面必须复用原数字人的本地 TTS、Web Audio analyser、Viseme timeline、本地面部 rig 和取消契约；仅保留一张静态人物图不视为数字人口型实现。
12. V1.5.3 键盘动作必须进入显式键盘状态并请求 Windows 系统屏幕键盘；底部输入模块使用稳定三列槽位，不使用嵌套硬描边、竖向强调线或整页侧边阴影轨。

## 16. V1.5.2 自动聆听、双输入融合与口型恢复验收补充

### 16.1 本轮交互基线

- 默认态是“自动聆听可用”，不是必须先点一次麦克风才进入连续模式。
- 语音与键盘不是两个并列模块：实时转写、最终识别和键盘输入都落入同一输入栏，清空、修改、敏感确认和发送均在原位完成。
- 输入栏获得焦点即进入键盘优先；麦克风按钮明确表示暂停或恢复自动语音。回答播报完毕且输入栏为空时，自动语音恢复。
- 无语音属于可恢复空轮次；权限拒绝、模型缺失和本机服务不可用属于停止自动循环的故障，二者不得显示成同一种错误。
- 普通回答必须同时具备文字、本地 TTS 与音频时钟口型；任一媒体失败都不能阻断文字，且不得用静态头像冒充正在播报。

### 16.2 浏览器验收状态

- **已验证范围：** `http://127.0.0.1:4173/` 本机 Vite 运行态中的默认自动聆听、麦克风暂停/恢复、语音/键盘同栏切换、普通问题提交、本地回答播报、可见本地口型、无语音后自动重试、播中开麦打断，以及播报结束后恢复聆听。
- **口型时序证据：** 当前 Vite 同源离线 TTS 运行态返回 `sensevoice-character-timestamps`，数字人以真实 PCM 音频时钟推进字符时间戳口型；活动帧最大 `data-jaw-open=0.65`，打断后回到 `CLOSED/0`。
- **安全确认：** 会员、积分、余额和本人账户文字保持原位确认，不进入普通问题自动发送。
- **本机边界：** ASR/TTS 只访问同源本机服务；固定站点数据仍来自本地 fixture，不连接生产会员系统。
- **浏览器证据用途：** 可证明前端状态机、本机语音接口与动态口型在开发运行时连通；不能证明便携包、实体终端扬声器、麦克风权限、后台节流或长期稳定性。
