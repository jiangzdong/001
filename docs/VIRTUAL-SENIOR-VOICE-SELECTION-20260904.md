## 已有候选

- 生成器 v1.5.0 为全部 10,000 个居民增加确定性中文模拟姓名。ID、权限、健康状态的取值盐不变；姓名进入导出、档案、健康上下文、详情和绑定，按姓名/编号/ID 搜索。重名合法，身份仍由 ID 和数据集版本确定。
- `selectJourneyRounds` 支持默认全 22 项、单选、多选；拒绝空选、重复、未知项和超限。按固定顺序执行，并显式返回 `selectedRoundIds`、`prerequisiteRoundIds`、`selectionReason`。例如只选重复提交，执行半年体征→合成保存→重复提交；不伪造前置数据。
- `prepareRetry` 仅接受报告 ID，从服务端历史取回原居民、数据版本与轮次，创建新会话/报告，记录 `retryOf`，不覆盖旧报告或沿用写入幂等键。数据版本改变时拒绝静默重测，需重新选择当前画像。尚未接入 IPC 和 GUI 按钮。
- `voice-trial` 独立模块涵盖问题合成、问题播放、本地识别、实际识别文本进入响应器、完整回答分段合成、完整回答播放；缺模型/播放器、静音、未播放完、超时、取消或识别错误都不能作为语音通过。长回答不会被原语音服务 500 字限制静默截断。
- 当前 live-session 仍是原文字执行器；新语音模块尚未接入它。报告新增 `acceptance.status=blocked` / `MANDATORY_VOICE_NOT_CONNECTED`，明确文字执行完成不等于必测语音验收完成。不得发布这一中间态或将旧 UI 的完成标签当成新增需求已实现。
