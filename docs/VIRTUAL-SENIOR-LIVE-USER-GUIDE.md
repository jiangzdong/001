# 单人观察测试：使用说明

适用：小安站点咨询顾问 V1.5.23，macOS 本机合成数据测试。

1. 双击 App，点击右上角三个点进入“终端设置”。
2. 点击“虚拟长者测试”，再点击“启动虚拟长者测试”。不用输入密钥，不需要命令行。
3. 在“单人观察”搜索居民编号，例如 `SYN-00231`，点击该居民。该示例有本人授权及健康记录；`SYN-00001` 用于检查无健康记录。
4. 默认已选“完整场景多轮测试（22 轮）”，无需逐项选场景。需要定点排查时，下拉仍保留原有单场景。点击“查看资料”可先检查合成体征及权限。
5. 点击“开始测试”。同一长者连续完成 22 轮问答，右侧逐轮显示场景及结果，约 35 秒（含每轮 1.6 秒观察停留，不是接口性能指标）。宽屏左控右看；窄竖屏自动切到“观察界面”。运行时可点击“停止测试”，结束后可换人再测。
6. 点击“查看本次结果”：逐轮状态/查询耗时、5 MCP/16 Tool 实际调用与成功数、阻止/失败/跳过数；“测试记录”保留最近 50 次，重启后仍可查阅。计划覆盖不等于实际成功。

完整旅程：服务目录→服务详情追问→站点知识→活动及翻页→合成身份→权限→档案→会员积分/等级→充值及翻页→消费及翻页→健康上下文/最新体征/半年体征及翻页→测评及最新测评→确认保存合成草稿→重复提交检查。追问使用同会话前轮返回的服务 ID、分页游标和证据 ID。

推荐先试 `SYN-00231`（有授权且有近期证据，检查 16 工具成功），再试 `SYN-00009`（匿名，检查个人数据被阻止）。每位居民都会安排全旅程，但无权限/无证据时不会强行读取或写入。

批量回归仍在顶部“批量测试”：选运行档位 → 生成并验证 → 统计分析。单人记录与批量通过率分开保存。

## 边界

- 当前测试使用独立合成数据与确定性多轮脚本/回答，不连接正式长者资料，不消费付费模型额度，也不代表自由对话模型的理解能力通过验收。
- 右侧复用正式产品的问答与数字人组件，但本轮是文本联调；没有运行麦克风、语音识别、语音播报或口型验收。
- 健康体征包括收缩压、舒张压、心率、血糖、血氧、体温，以及体重、步数。过期、无记录、缺失和权限不足均保留为测试状态，不填假成功。
- 测试指标枚举不能直接视为生产接口合同；正式个人健康查询仍需身份、同意及接口合同验收。
- 保存只写合成 Fixture 的测试记录，需预授权画像、前轮健康证据和脚本中的明确确认，不改变生产访问策略。重复提交检查比较真实返回的结果 ID，不模拟成功动画。
- 原 V1.5.22 App 保留，新候选生成在独立的 `release/multi-turn-v1.5.23` 目录，不覆盖旧包。
